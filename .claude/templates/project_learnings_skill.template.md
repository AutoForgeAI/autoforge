## How to Maintain This File

- Keep entries short: one bullet, one lesson, written as an instruction.
- Only record things that are specific to THIS project and not obvious from
  reading the code (e.g. "Run `npm run db:push` after changing `schema.ts`",
  not "Write clean code").
- Prefer refining or replacing an existing bullet over adding a near-duplicate.
- Delete bullets that are no longer true.
- Keep the whole file under ~150 lines; consolidate when it grows.
